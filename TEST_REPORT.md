# KASE Lens — Technical Verification Report

## В этой поставке

- **41/41** автоматических тестов Node.js: `npm test`.
- **16/16** маршрутов по сценариям стресс-тестов: проверка на воспроизводимых модельных ответах, включая корректные и некорректные. Дополнительно — тесты выбора источника и отказа от выдуманных чисел.
- **5/5** HTTP end-to-end проверок Node.js ↔ тестовый сервер Ollama: ETF, AIRA live quote, USD/KZT live rate, учебный убыток, вопрос вне тематики. Статус модели через `/api/status` также успешно получен от имитированного сервера.
- JS/Node module syntax and static asset build: `node --check`, `npm run build`.

**Ключевое ограничение верификации:** в среде проверки нет установленной реальной Qwen3. `mode=ollama` в тестах доказывает, что код способен отправлять запросы в совместимый HTTP endpoint Ollama и обрабатывать ответы. Это не доказывает стабильное качество реального Qwen3 1.7B, его скорость на Windows или семантическую корректность всех будущих генераций. Графический браузер этой среды блокировал навигацию, поэтому визуальный end-to-end UI тест не подтверждён.

## Что не гарантировано

- Ни один словарный классификатор не распознает 100% вариантов формулировок. Для продакшена нужны более обширные тесты, модели распознавания намерений и мониторинг качества.
- Фильтр чисел, покрытие ответа и правила противоречий — эвристики, а не доказательный семантический fact-checker. Возможны как ложные срабатывания, так и пропущенные ошибки.
- Известные источники представлены короткими пересказами публичных материалов. `Source` не равнозначен подтверждению любого произвольного вывода AI.
- Живые биржевые данные не подключены; полные биржевые интеграции требуют технических и правовых договорённостей.

**Итог:** сборка пригодна как демонстрационный, локально запускаемый AI-прототип с обозначенными ограничениями. Не сертифицирована для финансовых решений, публичной торговли или промышленных консультаций.
