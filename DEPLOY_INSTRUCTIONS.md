# KASE Lens — подключение настоящего онлайн AI

**Это обновление для существующего `Bigfigboy/kase-lens`, не новый проект.**

## Что обновилось
- Public AI Research доступен через `POST /api/ask` (сервер Vercel).
- Модель по умолчанию: `nvidia/nemotron-3.5-lightning-free` через Vercel AI Gateway, **не Gemini Plus**. Бесплатность — временная промоакция; при её окончании `-free` остановится, вместо перехода на платную модель.
- Используются проверки запроса, детерминированная арифметика, проверка чисел, релевантный RAG; нет живых биржевых котировок.
- API ключи **не хранятся в HTML и GitHub**. Vercel выдаёт своему серверу OIDC при включённом AI Gateway.

## Обновление репозитория
1. Распакуйте этот ZIP. Скопируйте **в корень** репозитория `public-demo.html`, `package.json`, `build.mjs` и папку `api/` с `ask.js`.
2. Commit в GitHub. Сохраните существующие `src/`, `rag/` и другие файлы — они не изменяются.
3. В Vercel убедитесь, что выбран **тот же** проект `kase-lens`, и включите **AI Gateway** в настройках проекта, если он выключен.
4. Параметры деплоя: Framework = Other; Build = `npm run build`; Output = `dist`. При необходимости Redeploy.
5. В браузере откройте `https://kase-lens.vercel.app/` → AI Research. Тестовый вопрос: «Чем ETF отличается от акции?».

## Возможные ограничения
- AI Gateway зависит от активации Gateway, условий аккаунта и лимитов. Для бесплатных кредитов Vercel может потребовать верификацию платёжного метода. Не включайте автопополнение.
- Бесплатный NVIDIA-провайдер может временно быть недоступен и может использовать вводимый текст согласно своей политике обработки данных. Не вводите личные сведения.
- AI и RAG **не заменяют инвестиционного консультанта**. Нет live market data, API не должен выдумывать актуальную цену или гарантировать прибыль.
- При ошибке онлайн-модели приложение сообщает о недоступности вместо имитации ответа.

## Важно
Не публикуйте секретные ключи. Подключать университетскую подписку Gemini к API не требуется.
