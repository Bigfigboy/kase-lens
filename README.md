# KASE Lens — submission-ready local AI prototype

**KASE Lens** — независимый учебный прототип финансового AI-помощника для первого этапа чемпионата KASE. Это **не официальный сервис KASE**, не инвестиционная рекомендация и не система совершения сделок.

## Запуск на Windows без платного API

1. Распакуйте архив **на диск D**, например в `D:\KASE_LENS_SUBMISSION`.
2. Проверьте, что установлена программа [Ollama](https://ollama.com/), а модель `qwen3:1.7b` уже доступна (`ollama list`). Если модель уже скачана, **скачивать заново не нужно**. Используйте `OLLAMA_MODELS=D:\OllamaModels` для размещения моделей на D.
3. Нужен установленный Node.js 20+.
4. Запустите **`START_KASE_LENS.bat`** или откройте эту папку в VS Code и выполните:

   ```powershell
   npm run dev
   ```

5. Откройте `http://localhost:5173`. Для технической проверки: `http://localhost:5173/api/status` — `ollama: true` и `installed: true` означают, что локальная модель доступна.
6. Если порт занят: `$env:PORT=5175; npm run dev`, затем `http://localhost:5175`.

**Не открывайте `index.html` простым двойным щелчком:** для AI необходим локальный Node.js backend. `npm run build` собирает лишь статический интерфейс; статический хостинг Vercel не получит доступ к Ollama на вашем ПК.

## Что умеет продукт

- **AI Research:** ищет относящиеся к вопросу записи в локальной библиотеке официальных материалов, передаёт их Qwen3 и показывает сгенерированное объяснение с явно обозначенным уровнем проверки;
- **Evidence retrieval:** предметный поиск по документам KASE, SEC Investor.gov и ARDFM; ссылки и дата проверки каждого локального пересказа;
- **Контроль смысла запроса:** различает живую котировку, исторический рейтинг, невозможную гарантию прибыли, рискованный персональный совет, учебную арифметику и вопрос вне тематики;
- **Арифметический модуль:** вычисляет заданные пользователем учебные проценты из исходных чисел **без** генерации рыночных значений;
- **Генерация на RU, KZ, EN:** языковая обработка и валидатор, включая казахскую кириллицу (качество на маленькой Qwen3 может различаться);
- **Market Explorer:** строго датированный снимок рынка за 19–20 октября 2026 года, **не живые котировки**;
- **Risk Lab:** учебный сценарий влияния гипотетического изменения цены одной бумаги на портфель;
- **Knowledge Studio:** вручную добавить краткий текст разрешённого открытого источника с HTTPS-ссылкой. Добавленный текст не считается автоматически проверенным и не дообучает веса Qwen3.

## Доказательства и безопасность

- Вопрос о **текущей** цене AIRA / курсе USD/KZT → `insufficient`: в проекте нет прямого фида биржи, исторические значения не выдаются за текущие.
- **Топ-3 всех акций за 30 дней** → `insufficient`: две даты по десяти компонентам индекса не образуют полного рынка и месячной истории.
- Запрос **сфальсифицировать рост HSBK** → `guardrail`: нельзя приписывать KASE неподтверждённые результаты.
- **Гарантированная доходность, персональная покупка на заёмные средства** → предупреждение об инвестиционных рисках без тикера к покупке.
- **Простой учебный убыток 100 000 ₸ и −12%** → 12 000 ₸ убытка, 88 000 ₸ остатка, вычисляется кодом, не языковой моделью.
- **Завтрашняя цена облигации по изменению базовой ставки** → объяснение, почему недостаёт исходных параметров для точной цены.
- **Образовательный вопрос, не покрытый корпусом** → возможно самостоятельное AI-объяснение с явной отметкой `GENERAL AI · UNVERIFIED`; никаких придуманных живых цен.
- **Релевантный документ, но некорректное объяснение** → до двух попыток Qwen3; после этого только документальные фрагменты (`evidence-only`), а не выдача плохого ответа за точный.

Использование термина «проверенный» относится к определённым фактам источника и программным расчётам, **не** к любому утверждению, сгенерированному языковой моделью. Проверка полноты и фильтры не заменяют независимый финансовый fact-checking.

## Состав файлов

- `START_KASE_LENS.bat` — запуск на Windows;
- `server.mjs` — локальный Node.js API, работает только на `127.0.0.1`;
- `src/answer-service.js` — генерация и безопасная обработка;
- `src/intent.js` — требования пользовательского запроса;
- `src/knowledge.js`, `rag/corpus.json` — предметный поиск и зафиксированные материалы;
- `src/verification.js` — проверка языка, чисел, полноты и нескольких опасных утверждений;
- `src/engine.js` — только проверяемые вычисления для UI, **без маршрута готовых чат-ответов**;
- `src/app.js`, `src/style.css`, `index.html` — интерфейс;
- `tests/` — автоматические проверки;
- `TEST_REPORT.md` — реальные результаты и ограничения;
- `TEAM_HANDOFF.md` — пояснения напарнику для презентации и защиты.

## Ограничения

1. **Локальная Qwen3 не доступна удалённому жюри по ссылке**, пока отдельно не развернут backend с моделью или API. Для этапа 1 рабочий прототип не обязателен; демонстрация возможна с компьютера разработчика.
2. Автоматического обновления котировок, просмотра всей истории торгов и полного поиска по KASE нет.
3. Данные сайта и источники ограничены публичными короткими пересказами, подтверждёнными источниками и исторической таблицей. В промышленных условиях необходимы юридическая проверка использования рыночных данных, более широкий корпус и независимая проверка ответов.
4. Модель `qwen3:1.7b` ограничена в сложном рассуждении и использовании RU/KZ/EN; любой её ответ, помеченный как непроверенный, следует оценивать критически.
5. Никаких брокерских операций, поручений на сделки и персональных инвестиционных рекомендаций продукт не выполняет.
